# Loqii Brain

Short, high-signal lessons only. Add durable rules, not session notes.

## Wisdom

- Truth has one owner.
- Debug belongs behind flags.
- Static shells prevent UI collapse.
- Billing changes require rollback first.
- Repo boundaries are product boundaries.
- Fake metrics are worse than missing metrics.
- Theme tokens prevent split-brain UI.
- Sync scripts are the release boundary.
- Map blast radius before crossing repositories.
- Diagnostics are a privilege, not a default.
- Tests are part of the change, not afterthoughts.
- Feature flags are release gates.
- Settings is stable config; Dev is experiment control.
- Persistent modals must declare every close path.
- Production config fails closed before UI boot.
- Dev degraded mode may unblock login, never backend-owned truth.
- Public config may identify the app; privileged bootstrap may trust the app.
- Normal dev boot should not test privileged trust unless explicitly asked.
- Before changing session/start/stop/auth/Decart/billing code, read `CHECKPOINT_RUNTIME_STABLE_2026_05_29.md` and preserve its runtime invariants.
